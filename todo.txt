#REPO MANAGEMENT NOTES#
 One-time setup:

  1. Keep your main AWOC repo as your development workspace
  2. Structure it like:
  AWOC/
  ├── addons/
  │   ├── buttered_sausage/      # standalone lib
  │   ├── resource_management/    # depends on buttered_sausage
  │   └── preview_window/         # standalone or depends on others
  └── [AWOC-specific code]
  3. Create separate GitHub repos for each component (empty to start)
  4. Add them as subtree remotes:
  git remote add buttered-sausage-remote https://github.com/you/buttered-sausage.git
  git remote add resource-mgmt-remote https://github.com/you/resource-management.git

  Daily workflow:
  - Edit everything normally in AWOC repo
  - Commit changes like usual
  - When a component is ready to release:
  git subtree push --prefix=addons/buttered_sausage buttered-sausage-remote main

  For dependencies:
  In the standalone repos' READMEs, just document "Requires Buttered Sausage" with a link. Users installing from Asset Library will see this.
